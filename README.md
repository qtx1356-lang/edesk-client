# eDesk — Windows Remote Desktop

A free Windows remote-support project based on a fork of RustDesk.

## Planned features
- Remote screen viewing and keyboard/mouse control
- File transfer
- Two-way voice during a remote session
- Device ID and session approval
- Self-hosted rendezvous and relay infrastructure

## Important status
This is a starter scaffold, not a working remote desktop executable. The next step is to fork the official RustDesk client repository and build an unmodified baseline before changing branding.

## Upstream projects
- Client: https://github.com/rustdesk/rustdesk
- Server: https://github.com/rustdesk/rustdesk-server
- Windows build guide: https://rustdesk.com/docs/en/dev/build/
